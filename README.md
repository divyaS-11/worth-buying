🛍️ Worth Buying

**Buy Smarter. Waste Less.**

Worth Buying is a product recommendation website designed to help users make smarter purchasing decisions. The website provides product details, specifications, ratings, reviews, pros and cons, and a **Worth Buying Score** before users visit external shopping platforms such as Amazon to purchase the product.

✨ Features

* 🔍 **Product Search** – Search products by name, category, or description.
* 📂 **Category Filtering** – Browse products by categories.
* ↕️ **Product Sorting** – Sort products by price and rating.
* ⭐ **Worth Buying Score** – Quickly understand the overall value of a product.
* ❤️ **Wishlist** – Save products for later.
* ⚖️ **Product Comparison** – Compare up to two products.
* 📋 **Detailed Product Pages** – View specifications, features, reviews, pros, cons, and FAQs.
* 🛒 **Amazon Product Links** – Visit the corresponding shopping page to purchase.
* 📱 **Responsive Design** – Works across desktop, tablet, and mobile devices.
* 🔔 **Toast Notifications** – Get feedback when adding or removing products.

🚀 Getting Started

### 1. Clone the repository

```bash
git clone <your-github-repository-url>
```

2. Open the project

```bash
cd worth-buying/client
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```

The application will run locally using the Vite development server.

🏗️ Build for Production

```bash
npm run build
```

The production files will be generated inside the `dist` folder.

🌐 Deployment

The project can be deployed using platforms such as **Netlify**, with the following Vite configuration:

```text
Base directory: client
Build command: npm run build
Publish directory: dist
```

For React Router routes to work correctly on Netlify, the project uses a `_redirects` file inside the `public` folder.

💡 Purpose

The goal of **Worth Buying** is to reduce the difficulty of choosing products online by presenting important information in a simple and easy-to-understand format.

Instead of immediately purchasing a product, users can first explore its features, advantages, disadvantages, and overall value before deciding whether it is worth buying.
